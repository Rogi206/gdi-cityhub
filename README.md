# GDI CityHub

**Tu negocio local, en la era digital.**

GDI CityHub es la landing page oficial de la agencia de transformación digital especializada en comercios locales. Construida con Next.js 16, Tailwind CSS v4 y componentes Radix UI / shadcn.

---

## Servicios

- **Páginas Web Profesionales** — Sitios modernos, rápidos y optimizados para SEO.
- **Apps y MVPs** — Aplicaciones móviles y productos mínimos viables para validar ideas.
- **Agentes IA Automatizados** — Chatbots y sistemas de atención al cliente 24/7.

## Stack Tecnológico

| Capa | Tecnología |
|---|---|
| Framework | Next.js 16 (App Router) |
| Lenguaje | TypeScript 5.7 |
| Estilos | Tailwind CSS v4 |
| Componentes | Radix UI + shadcn/ui |
| Formularios | React Hook Form + Zod |
| Gráficos | Recharts |
| Deploy | Netlify |

## Desarrollo Local

```bash
cd gdi-cityhub
pnpm install
pnpm dev
```

La app estará disponible en `http://localhost:3000`.
